# قائمة خطوات التشغيل الفعلي (Deployment) — معمل دولفين

> ده **خطة** للخطوة الأخيرة. **مفيش حاجة من دول اتعملت لسه.** نمشي بالترتيب، ومندخلش أي بيانات مريض حقيقية قبل ما قسم 1 يخلص.
> تاريخ كتابة الخطة: 21 أكتوبر 2026. أي معلومة مكتوب جنبها «غير متحقق منه (not verified)» لازم تتأكد قبل التنفيذ.

## 1. مراجعة قانونية (قانون حماية البيانات المصري 151 لسنة 2020) — قبل أي بيانات حقيقية

اسأل محامي متخصص في النقط دي:

- [ ] **بيانات الصحة "حساسة"**: أسماء المرضى + نوع الشغل (تقويم) تعتبر بيانات صحية؟ وإيه الشروط الإضافية عليها؟
- [ ] **الترخيص/التسجيل** عند مركز حماية البيانات الشخصية: المعمل محتاج ترخيص أو تصريح للتعامل مع بيانات حساسة؟ وإيه المستندات والرسوم؟ (غير متحقق منه)
- [ ] **الموافقة**: مين ياخد موافقة المريض الصريحة المكتوبة؟ الدكتور ولا المعمل؟ ونحتاج نص موافقة جاهز؟
- [ ] **نقل البيانات برة مصر**: سيرفرات Supabase وGoogle Drive برة مصر. ده مسموح؟ ومحتاج تصريح من المركز؟
- [ ] **واتساب**: إرسال أسماء المرضى على واتساب (للدكاترة أو بين الموظفين) مسموح؟ ولا نستخدم رقم الحالة بس؟
- [ ] **مدة الاحتفاظ**: نحتفظ ببيانات الحالة والنسخ الاحتياطية قد إيه؟ (النسخ دلوقتي: آخر 30 + نسخة شهرية لمدة 12 شهر)
- [ ] **الإخطار بالاختراق**: المدة والجهة. (البحث السابق لقى 72 ساعة — يتأكد من المحامي)
- [ ] **مسؤول حماية البيانات (DPO)**: المعمل الصغير محتاج يعين واحد؟ (غير متحقق منه)
- [ ] **موعد التطبيق**: اللائحة التنفيذية صدرت (قرار 816 لسنة 2025). مصدر بيقول فترة السماح بتنتهي **31 أكتوبر 2026**، ومصدر تاني بيقول مفيش فترة سماح أصلًا. **المصادر متعارضة — غير متحقق منه (not verified).** ده بعد أيام، فالمراجعة دي أولوية.
- [ ] نكتب رد المحامي في ملف ونعدّل النظام لو لزم (مثلًا: نشيل اسم المريض أو نختصره).

## 2. إنشاء مشروع Supabase الحقيقي

- [ ] مشروع جديد على الخطة **المجانية**. (متأكد من supabase.com/pricing: المشروع **بيتوقف بعد أسبوع من غير استخدام**، و**مفيش نسخ احتياطي تلقائي** في المجاني — عشان كده النسخ في قسم 5 إجباري.)
- [ ] اختيار المنطقة (Region): الأقرب لمصر (مثلًا أوروبا) — وده يتراجع مع المحامي (نقل البيانات برة مصر).
- [ ] تشغيل **كل** ملفات `supabase/migrations` بالترتيب في SQL Editor:
  `001_initial_schema` ← `002_owner_protections` ← `003_security_hardening` ← `004_permission_fixes` ← `005_work_types` ← `006_validate_assigned_technician` ← `007_atomic_technician_assignment` ← `008_unassign_in_progress_on_deactivation` ← `009_case_registration_history` ← `010_batch_cases_scope` ← `011_search_cases` ← `012_case_number_cairo_time` ← `013_late_cases` (الحالات المتأخرة).
- [ ] **ما نشغّلش** `scripts/seed_demo_data.sql` على المشروع الحقيقي.
- [ ] نكتب **رقم إصدار Postgres الرئيسي** (major) من لوحة Supabase (Settings ← Infrastructure). محتاجينه عشان `pg_dump` في قسم 5.
- [ ] نقفل التسجيل العام: Authentication ← Sign In / Providers ← إلغاء **Allow new users to sign up**.
- [ ] مفتاح **anon** بس هو اللي يتحط في الموقع.
- [ ] مفتاح **service-role** عمره ما يتحط في الريبو ولا في المتصفح ولا في متغيرات الاستضافة. (الريبو **عام** — أي سر يتكتب فيه يعتبر اتسرق.)

## 3. إنشاء حساب المالك بأمان

- [ ] Authentication ← Users ← Add user: إيميل المالك + **باسورد قوي** (16 حرف أو أكتر، من مدير باسوردات).
- [ ] في SQL Editor:
  `UPDATE profiles SET role = 'owner', status = 'active' WHERE email = '<إيميل المالك>';`
- [ ] نتأكد إن حماية آخر مالك شغالة: نحاول نوقف المالك الوحيد أو نغير دوره ← لازم يرفض.
- [ ] تفعيل التحقق بخطوتين (MFA) للمالك لو متاح في Supabase والتطبيق بيدعمه — **غير متحقق منه (not verified)**؛ التطبيق حاليًا مفيهوش شاشة MFA.

## 4. نشر الموقع (استضافة مجانية من ريبو GitHub عام)

| | Vercel Hobby | Netlify Free | Cloudflare Pages Free |
|---|---|---|---|
| استخدام تجاري على المجاني؟ | **لأ** — «non-commercial, personal use only» (متحقق) | مفيش منع مكتوب في الشروط (متحقق)، بس ممكن يقفلوا المشروع المجاني «without notice» | مفيش منع مكتوب في الشروط (متحقق) |
| ريبو GitHub عام؟ | غير متحقق منه | غير متحقق منه | غير متحقق منه (الربط بـ GitHub موجود) |
| تحويل كل الروابط لـ index.html | لازم `vercel.json` (rewrite) | لازم `public/_redirects` فيه `/*  /index.html  200` | تلقائي لو مفيش `404.html` |
| الحدود | 100 GB نقل/شهر | 300 credit/شهر (الـ GB = 20 credit) | 500 build/شهر، 20,000 ملف |

- [ ] **التوصية: Cloudflare Pages** (مفيش منع تجاري، والـ SPA شغالة من غير ملفات زيادة). البديل: Netlify مع ملف `_redirects`. **Vercel Hobby لأ** لأن المعمل نشاط تجاري.
- [ ] نراجع شروط الخطة المجانية بنفسنا قبل التسجيل (الشروط بتتغير).
- [ ] أمر البناء `npm run build`، والمخرجات `dist`.
- [ ] متغيرات البيئة في لوحة الاستضافة: `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` بس.
- [ ] في Supabase: Authentication ← URL Configuration ← **Site URL** = دومين الموقع، و**Redirect URLs** = نفس الدومين.
- [ ] نجرب: تسجيل دخول، وفتح رابط داخلي مباشرة (مثلًا `/cases`) وعمل Refresh ← لازم يفتح مش 404.

## 5. على جهاز المعمل (النسخ الاحتياطي)

- [ ] نحدد **مستخدم Windows واحد ثابت** بيدخل كل يوم (الجدولة شغالة بعد تسجيل الدخول) — **لسه متحددش (not verified)**.
- [ ] من المستخدم ده: دبل كليك على `scripts\backup\setup-backup.cmd`.
- [ ] نتأكد إن `pg_dump` إصداره الرئيسي (17.x) **أكبر من أو يساوي** إصدار سيرفر Supabase اللي كتبناه في قسم 2. **لو السيرفر أحدث، لازم نحدّث `install-tools.ps1` الأول.**
- [ ] ربط Google Drive بـ OAuth client خاص بينا (نوع **Desktop app**، ومعمول له **Publish**) — التفاصيل في `docs/BACKUP_GUIDE_AR.md`.
- [ ] تشغيل أيقونة **«نسخة احتياطية الآن»** والتأكد إن الملف ظهر على Drive.
- [ ] **اختبار استرجاع حقيقي** بالمفتاح الخاص («اختبار استرجاع النسخة») والتأكد إن عدد الصفوف في **كل الجداول** مطابق.
- [ ] نتأكد إن المهمة المجدولة موجودة: `Get-ScheduledTask DolphinLabBackup` في PowerShell، وإنها اشتغلت بعد تسجيل الدخول اللي بعده (من السجلات).

## 6. المفتاح الخاص (مفتاح الاسترجاع)

- [ ] نسخة على **فلاشة** + نسخة **مطبوعة على ورق**، الاتنين برة الجهاز وفي مكان آمن.
- [ ] **مسح** الملف من سطح المكتب (ومن سلة المهملات).
- [ ] نجرب إن نسخة الفلاشة بتفتح نسخة احتياطية فعلًا (اختبار الاسترجاع باستخدام ملف الفلاشة).

## قبل إدخال أي بيانات حقيقية (Go / No-Go)

- [ ] رد المحامي مكتوب ومفيش مانع (قسم 1).
- [ ] كل الـ migrations لحد 013 متشغلة، والتسجيل العام مقفول، ومفيش service-role في أي مكان عام.
- [ ] المالك داخل بباسورد قوي وحماية آخر مالك شغالة.
- [ ] الموقع شغال على الاستضافة والروابط الداخلية بتفتح بعد Refresh.
- [ ] نسخة احتياطية اتعملت **واسترجاع حقيقي نجح**.
- [ ] المفتاح الخاص على فلاشة وورق، وممسوح من الجهاز.

**الحالة: كل البنود فوق «لم يتم بعد».**
